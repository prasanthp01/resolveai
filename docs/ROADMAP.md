# Roadmap

P1: signed outbound callbacks with independent delivery jobs; read-only deployment evidence; Markdown report export; richer per-run usage/timing views; optional playable demo recording.

P2: outbound customer-side collector, native monitoring integrations, SDKs, SSO, multi-tenancy, reviewed connector extensions, and independently authorized remediation. These capabilities are not present in v0.1.

Before wider operational use: stronger redaction coverage for each customer data format; externally protected audit storage; fuller PostgreSQL monitoring privileges through narrow aggregate functions; hostname/TLS pinning support; load and extended soak testing; live model evaluation with an explicitly configured budget; documented off-host encrypted backup implementation.
