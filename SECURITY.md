# Security policy

This public beta has no independent security certification or guaranteed response SLA. Only the current release line is maintained.

Report suspected vulnerabilities through the repository's private vulnerability-reporting feature when enabled. If that channel is unavailable, request a private reporting channel without posting exploit details, credentials, customer data, or operational infrastructure in a public issue. Do not test against systems you do not own or have permission to assess.

Include affected version, minimal synthetic reproduction, expected/observed behavior, and impact. The public demo is read-only and synthetic; it is not authorization to probe unrelated services on the host.

Known limitations and evidence are in docs/THREAT_MODEL.md, docs/SECURITY_CONTROLS.md, and docs/RELEASE_GATES.md. Enabling real connectors or external model transfer requires operator configuration and review.
