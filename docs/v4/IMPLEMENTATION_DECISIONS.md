# ResolveAI v4 implementation decisions

- App v0.3.0 introduces a separate ASGI sandbox. Private `app.main` keeps its authentication and durable PostgreSQL pipeline. No existing database schema migration is needed.
- Public sandbox storage is explicitly ephemeral and single-process: maximum 256 retained runs, eight active globally, two per signed anonymous session, four-second deadline, ten-minute TTL, and bounded event streams. Restart invalidates sessions/runs. This is deliberately distinct from private durable recovery.
- Browser input is closed and bounded. Visitors choose logs from safe fixture IDs; they cannot supply URLs, credentials, SQL or arbitrary log instructions. The injection fixture is quarantined. Numeric diagnostics materially change rule outcomes. Seed is provenance; the current rules use no randomness.
- Pacing of 60 ms at each workflow checkpoint allows cancellation and event flushing. Durations measure real server elapsed time including pacing. They are not model thinking time.
- Packaged starter schemas remain under contracts/baseline for historical reference. Public simulation now uses an explicit adapter to the verified local Contracts 1.0.0 release. All 22 vendored schemas have checksum tests. Schema/presets/run/events/result/error endpoints are contract-tested; canonical event/result references point to full domain diagnostics in output. SSE uses step/end and numeric cursors. Both original full-prefix requests and edge-stripped internal requests work.
- Portfolio must adopt the same pinned release; earlier starter-schema clients are not silently compatible. Shared deployment remains a separately verified integration step.
- AgentOps currently offers authenticated synthetic routing, not real incident inference. AgentOpsBridge checks the policy and fails closed. Its unavailable result preserves the incident, deterministic evidence and human review. Direct billable fallback is forbidden while central quotas cannot be guaranteed. The existing authenticated OpenAI-compatible path remains explicitly configurable and budgeted; no anonymous inference is exposed.
- Model fallback and workflow fallback are separate. The public faults exercise a mock provider failure and deterministic workflow fallback; no second real model is contacted. Synthetic ticket retries exercise idempotency without creating an external ticket.
- CaseStudy is an independently previewable reference UI at /projects/resolveai/app/studio. The canonical /projects/resolveai case study is owned by the Portfolio project; its embedded simulator can consume the published API. The detailed versioned architecture remains at /projects/resolveai/app/architecture. Existing root /architecture is preserved until coordinated migration.
- Existing HTTPS reverse proxy is Nginx. Supply a compatible fragment instead of replacing it with Caddy. The ResolveAI run may stage its isolated backend and static files; shared routing and homepage cutover remain integration-owned.
